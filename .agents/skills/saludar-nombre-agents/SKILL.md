# Saludar por nombre

Toma el nombre proporcionado por el usuario y responde únicamente con:

```text
Hola [nombre]!
```

Reemplaza `[nombre]` por el nombre recibido y conserva su escritura original.
No añadas introducciones, explicaciones, despedidas ni formato adicional.

Si el usuario no proporciona un nombre, solicítalo antes de responder.
